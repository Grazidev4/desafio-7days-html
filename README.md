# 🚀 Desafio #7DaysOfCode - GitHub & Web (Alura)

Este repositório contém o projeto prático desenvolvido durante o desafio **#7DaysOfCode** de GitHub, promovido pela Alura e instruído por Fabrício Carraro e Giovanna Moeller.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5**
- **CSS3**

---

## 📁 Estrutura do Repositório

- `index.html`: Estrutura principal da página web.
- `style.css`: Estilização e layout visual do projeto.
- `images/`: Pasta contendo os ícones e recursos visuais utilizados na interface.

---

## 📌 Objetivo do Desafio

O objetivo principal desta etapa foi praticar a criação de repositórios, versionamento de arquivos, upload de pastas de mídia e realização de commits direto na interface do GitHub, seguindo as boas práticas de documentação de projetos.
